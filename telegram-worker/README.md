# Заявки с сайта → Telegram (по темам)

Форма на сайте (`assets/script.js`) отправляет заявки на Cloudflare Worker
(`worker.js`), а тот пересылает их в Telegram-группу с темами (форум),
раскладывая по разделам «Выкуп» / «Займы» / «Инвесторам» в зависимости от
выбора в поле «Тема обращения».

Сайт статический (GitHub Pages), поэтому напрямую слать сообщения в Telegram
из браузера нельзя — токен бота пришлось бы держать в открытом виде в коде
страницы, и им мог бы воспользоваться кто угодно. Worker — это бесплатный
маленький сервер-посредник: держит токен в секрете и знает, в какую тему
что пересылать.

## Шаг 1. Создать бота

1. Откройте в Telegram **@BotFather**.
2. `/newbot` → придумайте имя и юзернейм (должен заканчиваться на `bot`).
3. Получите токен вида `123456789:AAExampleTokenHere`. Сохраните — он
   понадобится на шаге 4.

## Шаг 2. Создать группу с темами

1. Создайте новую группу в Telegram, добавьте бота как участника.
2. Откройте настройки группы → **Темы (Topics)** → включите.
   (Группа автоматически станет супергруппой — это нормально.)
3. Сделайте бота **администратором** группы, обязательно с правом
   «Управление темами» (Manage Topics).
4. Создайте темы, например:
   - 🏠 Выкуп
   - 💰 Займы
   - 📈 Инвесторам

## Шаг 3. Узнать chat_id и id тем

1. Напишите в группе (в любой теме) любое сообщение — например, «тест».
2. В браузере откройте:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
3. В ответе (JSON) найдите:
   - `chat.id` — это `TELEGRAM_CHAT_ID`, отрицательное число вида `-1001234567890`.
   - `message_thread_id` у сообщения — это id той темы, в которой вы писали.
4. Повторите: напишите тестовое сообщение в каждой теме (Выкуп/Займы/Инвесторам)
   и через `getUpdates` посмотрите `message_thread_id` для каждой.

Если `getUpdates` возвращает пусто — значит сообщения уже «прочитаны»
предыдущим запросом; напишите новое тестовое сообщение и запросите снова.

## Шаг 4. Задеплоить Worker

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com)
   (бесплатно, карта не нужна).
2. **Workers & Pages → Create → Create Worker.** Дайте имя, например `cvn-lead-relay`.
3. Откройте редактор кода (Quick Edit / Edit code) и вставьте туда содержимое
   файла `worker.js` из этой папки. Сохраните и задеплойте (Deploy).
4. Откройте **Settings → Variables and Secrets** этого Worker'а и добавьте:

   | Имя | Тип | Значение |
   |---|---|---|
   | `TELEGRAM_BOT_TOKEN` | Secret | токен из шага 1 |
   | `TELEGRAM_CHAT_ID` | Secret | id группы из шага 3 |
   | `TOPIC_THREADS` | Plain text | JSON-карта, см. ниже |

   Пример значения `TOPIC_THREADS` (замените числа на свои id тем из шага 3;
   ключи должны **дословно** совпадать с текстом опций в форме на сайте):

   ```json
   {"Срочный выкуп недвижимости": 2, "Займ под залог недвижимости": 3, "Инвестиции в недвижимость": 4}
   ```

   «Другой вопрос» и любое значение, которого нет в этой карте, уйдёт в
   основную (General) тему группы.

5. После сохранения переменных нажмите **Deploy** ещё раз, чтобы Worker их подхватил.
6. Скопируйте адрес Worker'а — он выглядит как
   `https://cvn-lead-relay.<ваш-поддомен>.workers.dev`.

## Шаг 5. Подключить адрес на сайте

В файле `assets/script.js` найдите строку:

```js
const LEAD_WORKER_URL = 'https://cvn-lead-relay.YOUR-SUBDOMAIN.workers.dev';
```

Замените на реальный адрес из шага 4.6, закоммитьте и запушьте — после
деплоя на GitHub Pages форма начнёт реально отправлять заявки.

## Проверка

Откройте сайт, заполните и отправьте форму «Оставить заявку», выбрав любую
тему обращения. Сообщение должно появиться в соответствующем разделе группы
в течение нескольких секунд. Если появляется ошибка «Не удалось отправить
заявку» — проверьте:

- совпадает ли `LEAD_WORKER_URL` в `script.js` с реальным адресом Worker'а;
- заданы ли `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в переменных Worker'а;
- состоит ли бот в группе и является ли администратором.

Логи ошибок Worker'а смотрите в Cloudflare: **Workers & Pages → ваш Worker →
Logs (Real-time Logs)**.
